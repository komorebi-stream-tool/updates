# KOMOREBI

YouTube・Twitchのコメント、配信フレーム、通知、時計を表示するWindows向けの配信ツールです。

[最新版のダウンロードページ](https://github.com/komorebi-stream-tool/updates/releases/latest)

ZIPをすべて展開し、KOMOREBI.exeを開いてください。更新はアプリの「アプリを更新」から行えます。設定・登録GIF・接続情報はPC内に引き継がれます。GitHubのアカウントやAPIキーは不要です。

配信中はKOMOREBIを起動しておきます。更新による再起動は配信を終えてから行ってください。詳しい使い方とライセンスは配布ZIPに含まれます。

このリポジトリは配布専用です。個人の設定・登録素材・認証情報は配布に含めません。
